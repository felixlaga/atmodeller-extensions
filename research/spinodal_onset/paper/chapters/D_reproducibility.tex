\chapter{Reproducibility}\label{app:repro}

This appendix lists how every number and figure in this draft is produced. All paths are
relative to the repository root. The analysis used Python~3.13 with the package versions
recorded in \texttt{research/spinodal\_onset/outputs/provenance.json}.

\section{Pipeline}

\begin{enumerate}
\item \texttt{run\_study.py} computes the onset grid, the cooling paths, the source-data audit,
the homogeneous audit, the stress cases and the native \texttt{Atmodeller} solves.
\item \texttt{identifiability.py} builds the perturbation of Eq.~(\ref{eq:bump}) and checks that
it leaves every equilibrium quantity unchanged.
\item \texttt{digitize\_source\_figure.py} digitizes Figure~2a of \cite{gilmore2026} and compares
it with our implementation.
\item \texttt{calibration.py} runs the recalibration (Section~\ref{sec:recalibration}). The
environment variable \texttt{SPINODAL\_WORKERS} sets the number of worker processes (default 2);
with eight it takes about 40 minutes.
\item \texttt{design.py} computes the design screen of Section~\ref{sec:design}.
\item \texttt{make\_figures.py} writes the study figures and \texttt{outputs/key\_results.json}.
\item \texttt{make\_paper\_figures.py} writes all figures, and \texttt{paper/make\_numbers.py}
writes the computed numbers and table bodies to \texttt{paper/numbers.tex} and
\texttt{paper/tables}.
\item \texttt{heat\_study.py} computes the heat, nucleation and cooling results of
Sections~\ref{sec:heat}--\ref{sec:interior} in stages: \texttt{energy}, \texttt{edtable2},
\texttt{interior}, \texttt{barriers}, \texttt{delays}, \texttt{paths}, \texttt{checks} and
\texttt{planet}. The \texttt{checks} stage holds the sensitivity checks of
Section~\ref{sec:interior} and the interface width for half the window; the \texttt{planet}
stage integrates the heat along the digitized evolution of \cite{rogers2025}. \texttt{heat\_figures.py} draws Figures~\ref{fig:nucleation},
\ref{fig:parcel} and~\ref{fig:interior}, and \texttt{paper/make\_heat\_numbers.py} writes
\texttt{paper/heat\_numbers.tex}.
\end{enumerate}

Most computed numbers in the text are macros generated from the output files, so rebuilding
the draft after a rerun updates the text with the figures. Some values are typed directly.
Source values, such as the bulk compositions of source runs, are listed in
Appendix~\ref{app:source}, and values from other studies are cited where they appear. Rounded
ratios follow from the macros. The remaining typed values are one-off checks and estimates that
no script in the pipeline regenerates:
\begin{itemize}
\item the pressure-offset and likelihood checks of Section~\ref{sec:recalibration} and the
$\hat R$ of $1/\tau$ in Section~\ref{sec:recalibrated};
\item the gradient-transfer, cell-size and excess-volume estimates of
Chapter~\ref{ch:discussion}.
\end{itemize}
The abstract and the conclusion repeat some of them. They must be rechecked by hand after each
rerun.

PYTHONPATH=. uv run python research/spinodal_onset/digitize_source_figure.py

PYTHONPATH=. uv run python research/spinodal_onset/make_paper_figures.py
PYTHONPATH=. uv run python research/spinodal_onset/paper/make_numbers.py
for s in energy edtable2 interior; do
  PYTHONPATH=. uv run python research/spinodal_onset/heat_study.py $s; done
PYTHONPATH=. uv run python research/spinodal_onset/heat_study.py barriers --start 0 --stop 201
PYTHONPATH=. uv run python research/spinodal_onset/heat_study.py barriers --start 201 --stop 402
for s in delays paths checks planet; do
  PYTHONPATH=. uv run python research/spinodal_onset/heat_study.py $s; done
cd research/spinodal_onset && PYTHONPATH=../.. uv run python heat_figures.py && cd ../..
PYTHONPATH=. uv run python research/spinodal_onset/paper/make_heat_numbers.py
cd research/spinodal_onset/paper && tectonic -X compile main.tex

\section{Data Provenance}

The ED Tables and Figure~2 of \cite{gilmore2026} are stored unmodified in
\texttt{research/spinodal\_onset/sources} with their SHA-256 hashes, source URLs and the
CC-BY-4.0 attribution. No source value was changed. Where the table and the figure disagree,
both are kept and analysed as separate data versions. The fiducial evolution and energy
budget of \cite{rogers2025} (their Figures~5 and~6) are stored as digitized curves, with the URLs
and SHA-256 hashes of the source figures; their digitization error is a few per cent. The thesis
layout reuses the KU Leuven
title-page logo of the bachelor thesis. Its use should be checked against the current KU Leuven
style rules before the draft is submitted or shared beyond this repository.
